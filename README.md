## 两条路：服务器自装 1Panel，还是用云应用 RCA

先说结论式的判断：需要 root 权限、要装应用商店之外的东西、想自己控制 Docker 网络和端口映射的，买云服务器自己装。只想快速把 AList、Cloudreve 这类现成应用跑起来、不想管系统更新的，可以关注云应用 RCA，但要先确认它现在是否已对外开放。

**服务器自装这条路**的流程不复杂。买机器时选预装 1Panel，或者买一台干净的 Linux 系统自己装。1Panel 支持 CentOS、Ubuntu、Debian 等主流发行版，也支持麒麟、统信这类国产系统，架构覆盖 x86_64、aarch64、armv7l、ppc64le、s390x、riscv64。安装是 root 身份跑一条官方脚本，脚本会检测环境、装依赖、部署面板，结束后在终端给出访问地址。1Panel 默认会生成一个随机安全入口，访问时需要带上这段路径，这是它的默认行为，不是可选项。

装完之后你能拿到的是完整的面板能力：网站管理、数据库管理、容器管理、文件管理、防火墙、计划任务、日志审计。1Panel 的应用管理基于容器技术，官方说法是这样可以降低漏洞暴露风险。应用商店当前官网显示共 234 个应用。

**云应用 RCA 这条路**是另一套东西。按雨云 2025 年 4 月 18 日的开发日志，它是基于 Kubernetes 开发的容器应用平台，内置 App、网站、数据库三大板块，带一个内置应用商店，首批上架数百款 App，并且适配 1Panel 等第三方商店。原文的表述是"让您可以在不买服务器的情况下快速部署包括 Alist、Cloudreve 等数百种热门应用"。

第三阶段内测加进来的能力，恰好是判断"要不要自己装面板"的关键：

- 数据库支持 MySQL、MariaDB、Redis，可以在图形界面里直接建库、建用户，高级参数可编辑，状态页实时从数据库读取运行状态；
- 安装需要数据库的应用时，可以直接选对应的数据库服务，地址、端口自动填入，用户名和密码在提交安装时自动创建；
- 计划任务支持 crontab 表达式和常用模板，定时在容器内跑脚本，内置日志能看执行状态和命令输出，官方举的例子是 Laravel 的 PHP 定时任务；
- 应用列表会列出已开放的服务，内外网端口一目了然，可点击复制地址和端口；
- 网站可以选择通过独立 IP 直接暴露到公网，不经过共享集群代理，官方称更适合生产环境；
- 支持反向代理类型的网站。

这份能力清单和自装 1Panel 有重叠，也有缺口。重叠在数据库、定时任务、反向代理这些日常操作；缺口在于你没有系统层的完全控制权，装什么、怎么配网络，取决于平台开放到什么程度。

**这里有一条时效红线必须说清楚**：上述内容来自 2025 年 4 月 18 日的第三阶段内测公告，原文明确写着"目前还在内测当中，正式上线请等待进一步通知"。公告提到前两个阶段已有超过 200 位用户参与，参加内测需要加内测群拿邀请码，内测用户在正式上线时会获得奖励。到 2026 年 11 月，它是否已经正式上线、正式版怎么定价，公开资料里查不到明确说法。所以别把云应用当成一个现成在售的产品去做预算，下单前先去官网或社区确认当前状态。

1. 只有一台服务器，装个面板管网站、数据库、几个容器，社区版的功能一个不缺；

## 1Panel 和宝塔，在雨云上怎么选

雨云对两个面板都提供预装支持，所以搜"雨云1Panel"的人，往往也在雨云加宝塔之间摇摆。两个都是成熟的国产面板，差别在技术路线和操作手感上。

| 维度 | 宝塔 | 1Panel |
| --- | --- | --- |
| 应用管理方式 | 以传统直接安装为主，PHP 多版本切换、LNMP 环境配置成熟；另有 Docker 项目管理和应用商店 | 原生基于容器技术做应用管理和部署，环境隔离更干净，迁移方便 |
| 界面风格 | 功能密集，老用户熟悉，插件体系庞大 | 现代化设计，界面简洁，需要理解一点 Docker 概念 |
| 适合人群 | 习惯传统 LNMP 运维、跑 PHP 站点的用户 | 偏好容器化、想要简洁界面的用户 |
| 安全入口 | 支持设置安全入口 | 安装后默认生成随机安全入口 |
| 应用商店 | 官方插件 100+，另有 Docker 应用商店 200+ 应用 | 官网当前显示 234 个应用，全部为开源应用 |
| 多机管理 | 面板内置节点管理，10.0 起免费且不限节点数 | 多机管理属专业版功能 |

这张表只讲事实，没有谁更好的结论。你原来就跑 PHP 站、习惯了宝塔的插件生态，换过去的学习成本是实打实的；你从零开始搭环境、以后打算全部容器化，1Panel 的路径更顺。

## 下单前要确认的四件事

1. **云应用 RCA 的当前状态。** 官方最后一次公开说明是 2025 年 4 月的第三阶段内测。如果你冲着"免服务器"去，先确认它现在是否开放注册、正式版如何计费，别按内测公告里的功能列表做采购决定。
2. **线路和流量模式。** 国内线路不限流量但带宽小，境外和大带宽线路给到 100M 以上、每月 1024GB 流量。跑面板本身不费流量，费流量的是你用它传文件、做下载站、跑同步。
3. **续费价和计费周期。** 月付价不等于长期成本。季付、半年付、年付通常有折扣，但折扣力度和续费规则要以官网下单页为准，公开渠道流传的折扣信息不可靠。
4. **预装面板与系统重装。** 选预装 1Panel 省事，但重装系统会清空数据。已经有数据在跑的机器，重装前先做备份。

最后给一条选择规则：

只需要一台机器管网站、数据库、几个容器，预算控制在月付二三十元，选国内线路的 KVM 标准版或中配版，装 1Panel 社区版，不用考虑付费档；需要更大带宽传文件、做境外访问，选大带宽线路的入门或标准版；需要多台机器统一管理、站点要上 WAF 和防篡改，先算清楚专业版的成本再决定，别为了一个功能买整档；完全不想碰 Linux 命令行的，去确认云应用 RCA 是否已开放，再决定要不要等。
